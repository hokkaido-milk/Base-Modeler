## Install

In Blender 5.2+, open **Edit → Preferences → Get Extensions**, choose
**Repositories → + → Add Remote Repository** and paste:

```
https://github.com/hokkaido-milk/Base-Modeler/releases/latest/download/index.json
```

Then search for **Base Modeler** and install it. Updates arrive through Get
Extensions, or from **Check for Updates** in the add-on's preferences. You can also
download `Base_Modeler.zip` from the [latest release](https://github.com/hokkaido-milk/Base-Modeler/releases/latest)
and use **Add-ons → Install from Disk**.

For simple posing, generate the rig and click **Add Pose Targets**. Move hand/foot balls with **G**, rotate them with **R**, and move the head ball to aim the head. See [Pose target controls](docs/TARGET_CONTROLS.md).
